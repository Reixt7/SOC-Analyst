Анализ безопасности протокола FTP

Цель: Показать уязвимость протокола FTP к перехвату данных в открытом виде

Инструменты:
Kali Linux (Атакующий/Аналитик) IP: 192.168.1.8
Metasploitable (Целевой сервер) IP: 192.168.1.5
Wireshark (Захват и анализ трафика)

Ход работы:
1. В Wireshark ввел в фильтр `ftp || ftp-data`.
2. С Kali подключился к Metasploitable введя его IP-адрес через команду `ftp 192.168.1.5`. 
3. Ввёл логин "msfadmin", в Wireshark показало код 331 что значит логин введёт верно и нужно ввести пароль.
4. Ввёл пароль "msfadmin", вышел код  230 которые означает **успешная идентификация**.
5. Загрузил файл с Metasploitable под названием "dont-touch.txt" 
6. Вышел введя команду `quit`

Также в ходе исследования применилась функция **"Follow TCP Stream"** для восстановления содержимого файла.
